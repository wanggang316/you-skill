# Context

Domain terms used in code, docs and the UI.

- **Global Search**: the app-wide search panel (`Mod+P`). One query finds hub skills,
  instruction templates and projects (with the User scope), and opens the selected item on
  its own page. The UI calls it "Search" (搜索).
- **Filter**: the text field at the top of a page list. It narrows only the list on the
  current page. It is not Global Search.
